# English Corner — Spoken English Institute Official Website

A high-converting, modern, fully responsive website built for **English Corner** (Trivandrum, Kerala, India), faithfully implementing the dark emerald & vibrant lime green design layout.

---

## 🌟 Key Features

1. **Pixel-Accurate Design & Branding**:
   - Deep forest green (`#051913`) background with ambient radial glow and vibrant chartreuse/lime (`#cbf438`) accents.
   - Glassmorphic sticky header with the **English Corner** logo, smooth navigation, and a quick *"Talk on WhatsApp"* button.

2. **Hero Section**:
   - Slogan: *"Speak English with Confidence"*.
   - Live badge: *"One-to-One Live Training"* with video indicator.
   - Social proof: 500+ Happy Learners & 4.9/5 Learner Rating.
   - 4-pill quick ribbon for rapid course exploration.

3. **Course Showcase & Interactive Modal**:
   - **IELTS Training** (Listening, Reading, Writing, Speaking, Band 7.0+ focus).
   - **Interview Training** (HR & Technical prep, STAR framework, self-introductions).
   - **Career Skills Training** (Workplace meetings, presentations, email etiquette).
   - **Personalised Spoken English** (1-on-1 live training, Malayalam-to-English transition).
   - Clickable cards open a rich modal with complete syllabus, duration, format, and direct WhatsApp booking.

4. **Interactive English Level Assessment Quiz**:
   - 5-question diagnostic quiz assessing vocabulary, grammar, and fluency hesitation.
   - Real-time progress bar with instant score calculation and proficiency badge (Beginner A1-A2, Intermediate B1-B2, Advanced C1).
   - Direct button to receive a custom learning plan on WhatsApp.

5. **Learning Plans**:
   - **Standard Plan** (30+ Interactive Sessions).
   - **Mastery Plan** (60 Interactive Sessions, highlighted with glowing border & crown icon).

6. **Learner Stories & Testimonials**:
   - Authentic student reviews (Anjana S. - IELTS, Arun K. - Job Seeker, Neha R. - Working Professional).
   - Interactive slider navigation.

7. **Interactive FAQ Accordion**:
   - Addresses Google Meet 1-on-1 format, Malayalam speaker guidance, custom timings, rescheduling, and free trials.

8. **Lead Generation & WhatsApp Integration**:
   - Floating pulsating WhatsApp button on bottom-right for instant 1-click chatting.
   - *"Book a Free Assessment"* modal with slot preferences and pre-filled WhatsApp dispatch.
   - Quick Enquiry contact form with Trivandrum location details.

## 🚀 How to Run Locally

Simply double-click `index.html` in any browser, or run a local web server:

```bash
# Python
python -m http.server 3000
```
Then visit `http://localhost:3000` in your web browser.

---

## 🌐 Deployment to www.englishcorner.in

This project is built with vanilla HTML5, CSS3, and modern JavaScript. It has zero build dependencies and can be deployed instantly to:
- **cPanel / Apache / Nginx**: Upload all files to `public_html`.
- **Netlify / Vercel / Cloudflare Pages**: Drag and drop the folder or connect Git repository.
